# v0.4.0：契约一致性、CLI 检查与兼容性诊断

2026-10-08；交流版本，不是 npm/API 版本。本轮已在宿主与独立工具库实施以下基础项：

1. 宿主统一维护表单命名类型和独立消息预览契约，SDK 构建不再字符串追加表单类型。
2. host-capabilities.json + 公开当前能力表，明确预览与未开放入口。
3. check:upstream 同步 16 个文件；包元数据按语义比较，不因对象键/files 顺序变化误报。
4. CLI doctor --host --require --json：只读源码诊断、基线指纹、稳定错误码和退出码；明确运行时未测。
5. SDK ErrorCode 补齐宿主已开放的 QUOTA_EXCEEDED，新增白名单一致性测试。
6. 宿主参考包补齐 form.schema.json 出包；不改包版本，不发布。

验收要求：正常基线匹配；变更/缺文件报未验证；认证等未开放能力报不支持；未知 ID 报错；诊断不执行候选源码；SDK/CLI 全套测试和实际 tarball 安装验证通过。能力清单不替代语义校验、权限判断和真实桌面联调。

后续修改宿主必须审查 doctor 的基线差异，执行受影响的测试后显式更新指纹，不能在每次 build 自动接受变化。本轮没有新增运行时能力协商、认证、Agent hooks 或表单直接调用 API。
