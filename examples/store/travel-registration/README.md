# Three-step travel registration · 三步差旅登记

Install from the curated test catalog, select a local project, and use the skill in chat. The form collects itinerary, purpose and a CNY budget, then asks for confirmation. Its output returns to the chat; it does not submit expenses or call a business server.

从精选测试目录安装后，选择本地项目，在聊天中使用。三步表单依次收集行程、事由与人民币预算、确认。结果返回聊天，不提交报销、不调用业务服务器。

No service configuration is required. / 无需服务配置。
