# 聊天授权队列优化

普通聊天的并发授权改为输入框上方的统一队列。默认显示首项详情，其余显示命令摘要及专家来源；面板可收起，新到达的请求不改变收起状态。列表高度受限，输入草稿保持可编辑。

复用 shadcn Collapsible、Checkbox、Button、Alert 和已有 ApprovalCard。协作任务保留已实现的单项审核、完成反馈和显式查看下一项流程，继续复用 ApprovalCard，不增加模态弹窗。

批量批准或拒绝仅针对用户手工选中的请求快照（ID、方法、完整详情）。新请求不自动选中；内容变化的请求不沿用原选择。逐项调用既有授权 API，遇到失败即停止，保留未完成选择供重试；任务停止、离开当前聊天或组件卸载后停止剩余提交。不会授予本任务内持久权限，也不会开启完全访问。

后端对相同 pending RPC ID 的重复事件去重。相同命令、不同 RPC ID 仍是独立请求，不能按命令文字合并。取消或结束的上下文拒绝授权提交；已有任务结束/重启逻辑继续清除过期请求。

范围：本轮是每个任务内的队列，不合并不同运行实例的权限，也不推断命令风险等级。跨任务统一授权中心和按风险分组可另行设计。

验证覆盖：并发请求、收起后新增请求、精确批量范围、失败停止、停止任务后的批量中止、重复 RPC、单项重试、深浅色和窄窗口，以及协作任务授权浮层。
