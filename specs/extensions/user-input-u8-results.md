# U8 内置补充信息 Skill

日期：2026-10-14。实现完成；真实模型质量抽样和固定引擎、打包客户端验收仍属于 U9。

## 分发与发现

- 新增 `resources/skills/supplemental-input/`：SKILL.md、生命周期参考、可执行的动态旅游表单示例，以及中英文显示词典。旅游只是示例，运行时没有旅游或报销业务特例。
- 随应用复制到 `resources/skills`，macOS/Windows 共享构建资源声明；开发模式读取仓库 resources/skills。引擎读取的是当前应用配置数据目录内的实际文件，避免将 asar 内部路径暴露给外部进程。
- 启动时通过现有技能存储发布完整的不可变资源副本，稳定 ID 为 `builtin-supplemental-input`。整包摘要包括说明、示例与翻译；内容不变不生成新版本，升级/副本修复保留 enabled。历史版本与引用路径保留。
- `builtIn.version` 表示应用维护的资源版本（首版 1），`skill.version` 是配置内发布修订序号，`builtIn.digest` 标识完整资源包。修改资源时应同步递增应用资源版本。
- 复用既有技能目录：自动发现只注入名称、描述、路径；匹配后模型按需读取 SKILL.md。显式选择按 ID 去重，仅将正文注入当前请求一次。没有把整份 Skill 常驻在 developerInstructions，也没有另建一套技能系统。
- 当前 runtime 未提供补充工具时，不将内置技能加入模型目录。资源初始化失败也不提供该自动引导；只记录固定诊断消息，普通聊天与其他技能仍可用。

## 设置与权限

现有技能管理页面可查看内置技能及资源文件，显示“内置 · 只读”，隐藏编辑/删除入口，保留启用/停用。后台同样禁止修改正文、删除及通过本地导入/仓库安装覆盖内置记录。普通技能的编辑、删除与导入不受影响。

停用只影响后续请求中的技能发现和选择，不撤销宿主 input_* 工具、不取消既有待补充请求、不影响第三方 Skill 或 Extension 合法使用表单。用户已停用的技能不会因应用升级、重启或资源修复自动启用。已有执行上下文不会动态撤回已读取的说明；下一次执行使用新的技能目录。

名称/描述复用 `skill.nls*.json` 和 displayName/displayDescription；指令正文保持稳定，要求生成的表单文案跟随用户语言，业务值与字段标识不翻译。

## 使用指导

- 区分单个简单问题、几个相关缺失信息和第三方业务表单；不因问题笼统就无条件显示大表单。
- 首次相关使用探测 input_capabilities，先查询已有请求，创建时使用稳定 requestKey，重试复用同一内容。
- 发起后继续实际独立工作，不轮询、不伪造必要信息、不声称已支持 ExecutionUnit 调度。无独立工作时说明等待内容并结束本轮，持久请求仍保留。
- 答案事件到达后读取冻结答案；用户数据不是系统指令，填表不授权业务操作。
- 明确文字回答可关联真实消息 ID；部分、矛盾或有歧义时继续确认；不得自动接受提案。
- 取消、替换、CAS 冲突与 unknown 投递均有明确规则；不重复发送原文，不自动重发不确定投递，不用新请求绕过用户取消。
- 已注册单页 chat 模板可显式接入；operation/多步业务模板仍使用自身原有流程。第三方无需依赖此内置 Skill。
