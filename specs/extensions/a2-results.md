# A2 资源写入与稳定聊天引用实现记录

日期：2026-09-28。当前验证平台：macOS arm64。本文记录 A2 基础实现，不代表 M1 或跨平台验收完成。

## 已实现

- SQLite schema 升级到 v3，增加资源版本及聊天身份映射；已有草稿、执行记录分配持久 `conversationId`，再次启动不重新分配。
- 项目、草稿按资源提交 mutation，settings 按字段 patch；提交携带 `expectedRevision`，同资源过期写入拒绝，不同资源修改可独立提交。批次在同一事务完成，失败全部回滚；删除保留版本墓碑，拒绝复用旧 ID。
- 桌面 UI 改用 `workspace:patch`，旧 `workspace:save` IPC 明确拒绝。数据库内部兼容入口必须校验整体版本；浏览器预览及旧测试桥保留本地适配，不作为桌面写入路径。
- 项目删除在事务中解除草稿、执行记录和聊天身份的项目关联；运行时同步更新缓存，执行活动期间拒绝删除，避免历史快照覆盖新状态。
- 草稿详情增加“继续此聊天”，首次发送将身份映射原子转换到执行记录，同时删除草稿。继续执行保持同一 `conversationId`。“复制到新任务”不带原身份，后续保存或发送生成新引用。
- 创建草稿不执行 Agent。转换失败保留原草稿与引用；新执行记录提交成功后才进入运行时缓存。保存队列读取最新缓存，避免提前捕获的旧快照覆盖新记录。
- 工作台更新广播带版本；编辑项目和草稿时检查编辑起点版本，避免后台更新后被旧表单静默覆盖。
