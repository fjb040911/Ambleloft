# U4 动态单页表单与共享字段渲染

日期：2026-10-14。状态：本阶段完成。模型工具绑定属于 U5，正式待补充区、草稿控制与提交交互属于 U6；本阶段没有对外宣告这些能力已可用。

## 实现

- `core/inputs/definition.cjs` 按冻结的 tools.schema.json 校验动态定义，只允许八种基础字段。拒绝未知属性、业务接口、脚本、operation、动态联动及来源身份注入。
- 校验 JSON 数据、字段语义、重复字段/选项、数值与日期边界、UTF-8 字节配额及预填值。预填不把字符串强行转换成数字，不接受未知字段。错误只返回字段路径，不回传答案正文。
- `createDynamic` 是内部入口，来源固定为 model，将定义转换为确定性的单页 chat 模板，再进入已有持久请求服务。重复请求复用记录；提交仍走答案与 outbox 的原子事务。
- 模型定义中的文字直接显示，`%key%` 保持字面量；选项业务值不翻译。宿主控件提示跟随应用语言。静态来源词典仍由可信来源解析流程负责。
- `FormFields` 抽取原 TaskForms 的字段控件，复用 shadcn/ui 的 Field、Input、Textarea、NativeSelect、Switch、Checkbox。原静态表单的 mixed、条件可见和重新确认入口保留。
- `InputRequestFields` 仅提供受控渲染适配：字段错误关联辅助说明、稳定实例 ID、必填语义，以及已回答/失效请求禁用。它不自行保存草稿或发送答案，不产生第二套提交逻辑。
- 校验器打包为独立资源 `tools/input-definition.cjs`，避免安装包运行时依赖开发环境中的 AJV 或源码 Schema 路径。
