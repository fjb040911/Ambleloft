# A3 扩展包、信任与授权实现记录

日期：2026-09-28。执行平台：macOS arm64。范围为包管理、持久状态、信任和授权基础，不包含 Node 扩展激活、页面桥、Agent 操作派发。

## 已交付

### 包与版本

- 设置 → 扩展支持选择 `.amble-extension` / ZIP 包，或显式选择开发目录；旧声明式 JSON 安装仍兼容。
- 包处理使用独立 worker，30 秒超时、512 MiB V8 heap 上限；包内代码不 import、不运行安装脚本，不安装 npm 依赖。依赖必须随包携带，开发目录也复制成快照。
- 压缩包最多 100 MiB、解压内容最多 250 MiB、条目最多 10000；清单及词典沿用 A1 的 256 KiB 限制。拒绝路径穿越、绝对/驱动器路径、反斜线、大小写与规范化碰撞、链接、特殊文件和不一致的 ZIP 内容。支持普通 ZIP store/deflate，拒绝加密、多卷及 ZIP64；嵌套归档不展开。
- staging 校验通过后按相对路径与实际内容计算 SHA-256，存放到 `extension-packages/revisions/<id>/<digest>`。宿主不原地修改 revision；相同摘要目标存在时比较内容，发生改动则拒绝复用。启用及恢复版本重新检查内容。
- 每次安装、手动更新和回退均由宿主显示代码信任确认，绑定具体摘要；同 ID 不能继承旧文本扩展的代码信任。开发目录当前采用每次手动加载重新确认，不隐式监听或自动重载。
- 更新持久记录 pending 后切换 active 指针；旧 revision 保留。启动发现中断的 pending 时保留旧 active、停用并显示诊断，由用户重新确认。A4 接入前没有运行实例，预留停止旧实例的协调入口，尚不宣称已验证运行中热切换。

### 数据与授权

- 数据库升级到 v4。独立安装、revision、grant 和私有数据表替代旧 setting 注册表；旧 setting 保留作迁移备份，只发布统一注册表。无效旧记录隔离并报告，保留有效旧文本页及导航命令。
- 当前一个 userData 数据库对应一个 profile，持久 default profile UUID；表的 profile 边界由数据库目录承担。两个隔离目录的安装/信任/授权不会继承。未来多 profile 共库时必须显式扩充复合键，不能复用当前隐式边界。
- 授权只覆盖清单声明的 capability，作用域为 `self` 或精确 `project:<id>`；宿主选择项目并确认，不提供通配项目授权。声明权限不等于已授权。
- 更新和回退清除已有 grants；停用、更新、撤权等改变持久 generation，卸载再装也不会复用旧 generation。资源检查校验信任、启用状态、generation、授权及项目存在性；调用绑定项目不得被替换。
- 私有 JSON KV、配置与加密 secrets 提供宿主内部存储接口。值不超过 256 KiB、键值总量不超过 10 MiB、最多 10000 条记录；版本与删除 tombstone 防止过期写入。配置 schema 在 worker 校验。secrets 通过宿主现有安全存储适配器加密，无可用加密后端则拒绝，不写明文。
- 私有数据按 `(extensionId, kind, key)` 分区；`kv`、`configuration`、`secret` 共用表，但分别检查权限，secret 列内容只接受宿主加密结果。未向 renderer 提供私有存储/secret 读写 IPC。
- 卸载由宿主询问保留或删除私有数据，清除安装/授权/信任注册；重装重新确认。包文件保留，不作为已信任或已安装的依据；启动仅清理中断 staging，历史包 GC 尚未实现。

### 管理界面

- 安装、加载开发目录、启停、版本恢复、授权项目、撤销全部授权、卸载数据选项均已接入。
- 项目使用宿主下拉选择器；确认展示目标扩展、项目及权限。
- 新包明确标注运行时尚未开放，不把“已安装/已启用”呈现成代码已经运行。旧文本扩展仍走原页面导航。

- `npm test`：126 项通过，0 失败；完整测试集含需要本地回环监听的测试。

- `node scripts/test-extension-packages.mjs`：真实 Electron、临时用户目录，通过设置页安装 → 信任 → 项目授权 → 更新清权 → 恢复旧版 → 停用 → 重启 → 启用 → 撤权 → 卸载。原生确认对话框由测试适配器响应；验证实际 IPC 和状态链路，不代替对系统弹窗的人工可用性验收。
- 测试包入口含抛错代码，整个 A3 流程没有执行入口。未使用用户真实模型服务或修改用户现有扩展。
