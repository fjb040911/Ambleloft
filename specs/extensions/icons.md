# 扩展图标规范（源码预览）

`extension.json` 顶层可声明可选 `icon`。图标用于首页左侧扩展列表、扩展首页卡片，以及设置中的扩展列表与详情。安装时读取图标，不需要启动扩展后台。

单张图适用于两种主题：

```json
{"icon":"assets/icon.png"}
```

也可分别配置浅色、深色主题：

```json
{"icon":{"light":"assets/icon-light.png","dark":"assets/icon-dark.png"}}
```

- 路径相对于扩展包根目录，必须随包分发；使用 `/`，不接受绝对路径、`..`、符号链接、HTTP URL、data URL 或运行时返回的图标。
- 首版仅支持静态 PNG，文件名以小写 `.png` 结尾。每张最多 64 KiB，正方形，宽高 16–512 像素；建议透明背景的 128×128 图片。不支持 SVG、动画 PNG 和动态图标。
- 分主题配置时 light 与 dark 都必填。它们对应应用当前实际主题，包括“跟随系统”计算出的主题；单图声明在两种主题使用同一图片。
- 侧栏显示区域为 18×18 CSS 像素；图片保持比例，不自动反色或改变颜色。建议主体居中、保留约 10% 留白，在小尺寸下清晰可辨，深色图应在深背景有足够对比。
- 图标属于包资源，不参与 `%key%` 多语言替换和 when 条件计算。名称与说明继续按既有多语言规则显示。
- 未声明时显示宿主默认拼图。声明后文件缺失、路径不合法、类型/尺寸/体积不符会拒绝安装。已安装图片若无法解码，界面回退到默认拼图，不影响扩展入口。
- 图标随包版本更新、回滚和卸载，不单独缓存远程资源。更新移除 icon 声明后恢复默认图标。

编辑器结构提示来自 `contracts/extension.schema.json`；宿主和 CLI `validate`/`pack` 同时执行包资源语义校验。SDK 不提供动态 setIcon 接口。
