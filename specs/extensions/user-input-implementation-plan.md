## 验收矩阵

| ID | 场景 | 预期 / 验证层 |
| --- | --- | --- |
| V01 | 运行中手动补充，随后继续输入 | 同一聊天/活动轮次；仅清空发送快照，不丢新文字；组件 + runtime |
| V02 | 同一输入 ID 重复发送、同 ID 不同内容 | 同内容复用回执；冲突拒绝；数据库 |
| V03 | preparing、结束边界、正常空闲 | 不向旧 turn 误投；明确未发送才重排；允许时同聊天开启下一轮；引擎 |
| V04 | 用户停止与待发 queued 同时发生 | 持久暂停未发送项，重启仍暂停；保存草稿不恢复，明确继续才恢复；已派发按回执核实；竞态测试 |
| V05 | 断线、超时、发送后应用退出 | unknown，禁止自动重发；只读核实，未找到仍不声称未发送；数据库 + 引擎 |
| V06 | 创建动态旅游表单、已知信息预填 | 接受已有字段范式；未提交不视为用户确认；模型/工具集成 |
| V07 | 动态定义带 operation/URL/脚本、越界字段、跨聊天请求 | 拒绝；不能绕过 Operation 授权或读取其他聊天；负向契约测试 |
| V08 | 表单等待时工具继续运行 | 请求立即返回，独立工具持续；此项不等同精确步骤恢复；确定性引擎集成 |
| V09 | 多窗口同时提交、点击两次、提交前后崩溃 | 一份冻结答案、一条投递项；CAS冲突可理解；数据库 |
| V10 | 滚动历史、隐藏dock、多个请求、切换语言 | 不丢输入/选择，不产生第二实例，不抢焦点；浏览器 |
| V11 | 原生问题回答、resolved、终止、重启 | 仅发原 RPC 一次，失效后无可点击旧按钮，不用 steer冒充回答；协议探针 |
| V12 | 修改需求后显式替换；取消；归档/停用来源 | 旧请求保留记录并禁用，用户草稿不被静默覆盖，无迟到重放；服务 + UI |
| V13 | 历史静态 chat/operation 模板、报销动作 | 原有授权/恢复保持；填写信息不授权业务写入；回归 |
| V14 | Skill 自动发现与多协议真实引擎 | 能探测、发起、接收和使用结构化答案；不轮询/伪造结果；引擎 + 模型抽样 |
| V16 | 明确文字回答、重复关联、跨聊天/助手消息伪造来源 | 明确回答关联并保留出处，幂等、不重复 steer；非本聊天用户消息拒绝；服务 + runtime |
| V17 | 文字歧义、部分信息、“其他你安排”、草稿冲突 | 不伪造必填答案；pending 或明确确认；不触发业务授权；Skill 行为 + 服务 |
| V18 | 未编辑直接替换、有未保存输入时替换、接受/拒绝与多窗口竞态 | 未编辑才直接替换；其他情况保留原草稿等待确认，CAS 拒绝过期接受；浏览器 + 数据库 |
| V19 | 稍后填写、取消请求、停止后取消 | 稍后仍待办；取消产生一次未获答案事件；停止后不自动恢复，必填不自动采用默认值；服务 + UI |
| V15 / P1 | A/B/C/D 依赖执行，B 等待答案 | A/C仅无依赖时继续，D阻塞，回答定向恢复B；完整调度集成 |

完成标准：单元测试覆盖状态与竞态，浏览器测试使用正式组件，Electron 集成使用隔离配置和固定引擎；另做真实模型质量抽样。Windows/macOS/Linux 的构建与实机结果分别记录，不能用 macOS/mock 结果代替全部平台验收。不依靠全量测试数量替代以上关键场景。
