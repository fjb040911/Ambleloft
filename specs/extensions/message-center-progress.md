# 消息中心宿主开发进展

状态：已打通本地范围消息的扩展发布、持久化和桌面 UI。消息模块整体未完成；SDK 与 CLI 由独立项目推进。

## 已实现

- 消息按 Profile、来源、账号范围存储；来源接收偏好跨业务账号共享。目前运行时仅开放 local 范围。
- 支持 eventKey 去重、拒收标记、内容版本、终态约束、过期、已读、清除、筛选和批量处理。清除及拒收保留去重标记，重复发布不恢复展示；阅读与清除不递增内容版本。
- 数据库 schema v6 持久化记录与偏好。宿主绑定 Profile 和来源，每次扩展调用校验安装、信任、启用状态及 generation。
- 扩展进程通过 context.messages 调用宿主；读取结果不暴露阅读和清除字段。具体边界见 [运行时对接说明](./message-runtime-handoff.md)。
- 消息中心提供未读徽标、来源与状态筛选、详情、标记已读及清除。批量清除跳过未完成待办，单条清除待办需确认。
- 设置 > 通知提供各来源的接收和静音开关。已读与偏好变更跨窗口同步，主进程检查过期并广播变更。
- 设置 > 账号提供多个企业连接配置的新增、编辑、删除和默认项选择；使用 revision 防止旧表单覆盖并发修改。配置仅保存名称、HTTPS issuer、clientId 和可选 tenant，不保存密码或 Token。

## 2026-10-08 增量实现

消息 Operation 按钮、持久化派发、幂等结果回报及原子消息更新已接入真实扩展进程与桌面。企业 OIDC 登录、宿主 HTTPS 代理、令牌加密和断开授权已开放预览接口。独立 SDK/CLI 已同步契约。详见 [接入规范](message-actions-auth-guide.md)。

## 明确未完成

全局多账号选择器、刷新令牌、账号作用域消息、WebSocket 凭据与正式运行时能力协商。实际企业 IdP、系统通知横幅/点击和跨平台发布仍须验收。不能将以下历史测试数量视为本次全量验收；本次证据见 [联调报告](../../tooling-report/2026-10-08-message-actions-auth/README.md)。

## 当前限制

当前内部上限：标题 1 KiB、正文 64 KiB、eventKey 512 字节、业务类型 256 字节，每范围最多 10,000 条记录（含去重标记）。这些限制尚未冻结为公共 SDK 契约。去重标记不自动淘汰。

## 系统通知投递推进

- 已接入 Electron Notification；宿主消息和扩展消息共用投递逻辑。只有首次发布成功且允许提醒的消息会投递，投递前重新检查已读、有效期与来源偏好。更新、撤回、重复发布不再次提醒。
- 点击系统通知会唤起窗口并打开消息中心。系统不支持或投递失败不影响消息持久化，重启不重放通知。
- 内置来源显示为 AmbleLoft，设置空状态不再暗示必须安装扩展。
- 服务测试覆盖新消息、重复、更新、静音、拒收及系统投递异常；实际操作系统通知横幅和点击行为仍待桌面验收。
