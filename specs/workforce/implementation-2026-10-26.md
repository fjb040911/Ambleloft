# 协作工作平台：业务实现与验证记录

2026-10-26。依据[需求 v0.4](../../../agent-flow/designs/agent-workforce/requirements.md)、[历史决策](../../../agent-flow/designs/agent-workforce/decision-log.md)和[10 月 25 日审计](business-audit-2026-10-25.md)。本次继续实现既定业务，没有修改验收条件来迁就代码。

本轮交付角色创建与激活、逻辑空间、资料采纳、LangGraph 工作包编排和授权原文查询的主链路。AI Coding 真实试跑验证了两位员工的技能、资料工具、草稿产物和依赖交接。**这不等于整个产品已经通过跨仓库施工、远端执行与长期记忆的完整验收。** 未完成范围保留在第 6 节。

## 1. 使用入口

从源码重新启动宿主，在 ActiveBar 或分组栏进入 **协作工作平台**。本轮修改了主进程和 preload，仅刷新渲染页面不能更新全部服务。

1. **角色库**：选择官方角色或“自己设计一个角色”，进入“选择起点 / 定义角色 / 声明技能 / 保存与激活”。模板直接进入定义；AI 引导与手工共用持久草稿。离开后可在我的员工继续原步骤。
2. **我的员工**：编辑、复制、查看激活进度或发起任务。仅保存不安装；激活复用全局技能并补齐缺项。失败可单项重试，成功项保留。
3. **项目空间**：创建只需名字；在“团队与项目”分别关联已有项目、添加员工并配置本空间职责和项目范围。无空间根目录要求。
4. **讨论**：选择成员或输入 `@`，选择资料和明确授权的历史空间。只启动所选成员；可继续上一轮、打开完整任务、汇集观点为可编辑草稿。
5. **文档与产物**：修改形成新版本，明确采纳后成为施工依据。最新草稿与旧采纳版并存；历史、来源任务、导出、撤回与恢复审阅均有入口。
6. **任务**：手工编辑计划，或让 AI 按目标、现有成员和所选资料提出建议。建议显式应用，保存不执行；启动后按依赖调度。交付进入审阅，验收通过才放行下游。
7. **知识与决策**：按空间/员工范围查询已采纳原文，打开版本、来源和适用条件。当前是本地来源检索，不宣称已接入 Hindsight。

[只读审阅页](http://127.0.0.1:4189/__review/?layout=activity&lang=zh-CN&view=spaces)使用宿主实际 React 界面和本轮已落盘的真实结果，不提供执行/编辑，不将测试数据混入日常用户资料。4185 仍是原型，4189 是实际结果审阅。

## 3. AI Coding 真实试跑

[verification.json](../../../agent-flow/.state/workforce-flow-20261026-r3/verification.json)记录结束于 2026-10-26 10:45（Asia/Shanghai），模型 `deepseek-flash`。输入是此前获授权的最小摘录：4,662 bytes，SHA-256 `0df1330526af19b6dfdd1a37cb41076b85f2f69fbe8e49fd285d9d02c4f09272`。没有发送完整资料或凭据，没有修改 AI Coding 仓库。

- 真实目录读取 7 个官方模板，产品经理/架构设计师各安装或复用 2 项真实技能。
- AI 角色建议与目标拆解均进行真实模型调用；建议不会自动覆盖配置或执行计划。
- 固定 v1 输入，两个依赖讨论包：产品经理先提出范围，架构师随后复核契约。
- 两位员工通过空间工具读固定资料，各提交一份带 sourceRunId、来源版本和 hash 的草稿；均保持未采纳。
- 测试在检查实际产物、来源和技能后，明确记录“仅验证交接机制”的验收才放行下游。这不是用户已批准业务设计。
- 最终 2 包完成交接，实际写入项目仓库次数为 0；不能据此宣称跨模块代码已交付。

保留中间失败记录：第一次规划输出被 2048 token 上限截断，已增加有界规划预算并明确报告截断；第二次发现引擎遗漏新空间工具的受控注册，工具被错误拒绝，已补齐确切工具名并增加回归检查。第三次试跑通过，没有将任意 MCP 工具设为自动批准。

复现脚本：`scripts/probes/workforce-flow.cjs`。需独立 profile 和已授权摘录目录，会调用外部模型，不是默认测试的一部分。

## 6. 继续保留的缺口

1. **多仓库与远端**：真实模型只测讨论和产物交接。文件型执行器独立 inputs/outputs 适配、远端传输、SSH/Docker 实际写入与验收仍待补齐；不能由本地 MCP 成功推导全部可用。
2. **长期记忆生命周期**：本地来源检索可用；Hindsight/Mem0 未定选或接入。自动经验提炼、候选/待复核完整流程、物理删除和备份周期未实现。撤回限制访问但保留审计；不承诺追回已向外部模型发送的内容。
3. **来源管理**：项目文件权威来源登记/迁移没有完整 UI。其他 Agent 技能目录可手工本地导入，未做自动发现；不能按模糊名称静默安装未知技能。
4. **恢复和性能**：检查点用固定版本 MemorySaver 序列化，后续迁移、保留上限和长期压力测试待补；大目录/远端指纹覆盖限制明确呈现，不算完整代码校验。
5. **完整宿主验收**：新原生窗口、崩溃恢复、跨平台打包及全部键盘焦点/错误场景待补。

旧工作区变更保留。本轮没有提交、推送、合并、部署或发布。
