# 协作计划流程图：实施与验证

日期：2026-11-02。基于用户“按照这个思路优化”的确认实施，覆盖 [GV 设计](plan-graph-view-v1.md)。保留仓库已有未提交工作；未修改真实计划、未执行真实授权、未发布应用。

## 本轮交付

- 多工作包计划默认流程图，单工作包默认列表；两个视图可以互换，按计划保存当前应用会话的偏好。
- 概览提供独立的“查看流程图”入口。计划标题、版本、状态和现有操作保持可见。
- 工作包为节点，保存的 `dependencies` 为箭头；显示负责人、项目、Local/SSH/Docker 环境、真实状态和阻塞原因。上游只有 `accepted && !stale` 才显示依赖满足。
- 选中节点突出传递上游和下游，同时打开原有任务详情。验收、重试、授权和补充信息仍在详情中处理；图仅负责导航。
- 缩放、背景平移、查看全图、循环定位待处理/执行中、拓扑顺序键盘访问。关闭详情恢复节点焦点；筛选仅淡化节点，不删除依赖中间环节。
- 字段、状态或同一 revision 下的快照刷新不重算布局，不自动居中。拓扑变化及用户调整字号可重算布局。视角按计划与拓扑保存在 sessionStorage；切换计划不混用。
- 窄窗口首次展示可读的起点视角；“查看全图”是显式缩小总览。详情在窄窗口替换画布，返回后保留视角。
- 手动制定/修订计划、讨论整理出的任务候选均提供未保存依赖预览。重复 ID、缺失前置和循环依赖明确报错，不绘制正常 DAG；手动编辑器的循环依赖不能继续保存。
- 补上归档空间的详情只读限制：不展示待处理操作卡，嵌入的业务表单按只读呈现；计划验收与调度按钮保留既有归档限制。

## 实现和依赖顺序

1. 纯图适配层：`src/workforce-plan-graph.ts`，拓扑验证、稳定 LR 布局、关系追踪、有效验收及预览数据转换。
2. 图组件：`src/WorkforcePlanGraph.tsx` / `src/workforce-plan-graph.css`，React Flow 12.12.0 + Dagre 3.1.3，固定依赖版本；节点位置不写入业务数据。
3. 计划、概览及导航：`WorkforcePlans.tsx`、`WorkforceSpaceOverview.tsx`、`WorkforceSpaces.tsx`、`workforce-space-state.ts`。
4. 候选预览：`TaskCreationGuide.tsx` 及既有 PlanEditor。共享状态文案提取至 `workforce-execution-state.ts`。
5. 归档详情：`TaskDelivery.tsx` 的展示级只读模式。

图不新增 Store、模型、数据库或调度 API。仅为 `SpaceDestination` 增加 UI 导航字段 `planView`。等待节点按需读取现有 run 分页（limit 1）中的授权/问题元信息；无法明确区分时仍显示“等待输入或授权”，不推测权限请求。详情继续使用现有完整请求和持久表单接口。

## 真实资料与模拟的边界

以只读 SQLite 连接核对宿主“设备维修工单测试项目 第一版协作计划”（revision 1）：**6 个工作包、6 条边、2 个独立起点、无拓扑错误**。当时契约为 review，环境核验为 failed，其余四包为 pending。这是对真实已保存结构的核对；不是新一轮远端执行。

## 使用、发布和剩余边界

本机依赖已安装。源码应用刷新前端后，从 **协作工作平台 → 项目空间 → 任务 → 流程图** 查看；也可在空间概览点击“查看流程图”。不需要重新生成现有计划。建议以“设备维修工单 · 协作试验”检查两个根任务、API 的双前置以及最终联调的合流。

其他开发环境先同步 package.json / package-lock.json 并按仓库流程安装依赖，再运行构建；打包发行仍走既有应用发布流程。本轮没有生产发布、数据迁移、Store 部署或计划自动恢复动作。

首版不包括拖线编辑、历史时间回放、跨计划依赖、自动追踪执行节点；当前会话以外的 UI 偏好不保证保留。Windows、打包版和真实 SSH/Docker 执行尚未在本轮验证。大图缩小总览时文字会变小，使用放大、定位或列表读取细节；没有将其宣称为可读的时间轴或甘特图。

## 执行动效补充

2026-11-02 增加有方向的执行反馈：有效已验收的前置任务指向 `running` 任务时，在静态依赖线上叠加向目标移动的亮段；执行节点边缘显示循环流光。无前置的执行节点也显示流光。待验收、等待授权/输入、准备、停止及失败节点不播放执行动效，未启动下游的连线保持静止。原实线/虚线和箭头始终保留，动效不改变依赖语义，也不修改调度。

修复状态刷新造成的连线闪动：受控节点每次更新都会被 React Flow 重置连接点测量，边因此短暂卸载。现为已有固定尺寸节点提供对应的尺寸及左右连接点几何，状态变化不再重新挂载边；字号变化仍更新实际几何，缩放/定位/查看全图保持可用。

动画使用 CSS SVG 描边偏移，连线每 1.2 秒移动一组亮段、节点每 3 秒循环一周，不增加依赖。图离开视口或页面隐藏时暂停；`prefers-reduced-motion` 下使用静态高亮。文字不闪烁，节点位置与视角不随执行状态改变。

验证：14 项图浏览器测试、6 项图数据测试及 TypeScript 检查通过。新增测试实际检查 SVG 偏移方向、刷新前后同一边 DOM 和动画时间保持、等待/停止等状态切换、离屏暂停、减少动态效果及失效前置不显示执行流向。检查了浅色、深色和窄窗口截图。上述执行状态来自隔离测试数据，未触发真实计划执行。
