# 角色库、员工档案与导航修复

日期：2026-10-26。对应用户当日反馈，范围限于角色浏览/添加、员工档案及编辑退出导航。本文不替代完整协作平台验收。

## 业务与修复

- **角色模板**：名称或“查看详情”打开只读 Dialog，展示专业方向、职责、交付、方法/边界、推荐技能、具体来源和版本。打开/关闭不创建员工、不生成草稿、不触发安装；明确“添加为我的员工”后才进入现有四步编辑器。
- **我的员工**：查看实际保存的档案、配置版本和状态；“编辑员工配置”是独立动作。技能准备期间不允许编辑，已有任务保留原有配置快照。
- **错误与键盘**：添加失败在详情内呈现，可关闭/重试；Esc 关闭后焦点回到原按钮，列表搜索保留。内容独立滚动，底部动作可见。
- **侧栏锁死**：复现“返回我的员工”关闭编辑器后，卸载组件来不及通过 busy effect 清除父组件状态。修复为关闭时复位、卸载时释放，并把导航锁定条件限定为仍挂载的编辑器。
- **头部偏移**：宿主不使用 Tailwind preflight，Breadcrumb 的 ol 带浏览器默认编号及 40px 缩进，同时继承旧 nav 内边距。组件内显式重置，保留原有其他列表样式。面包屑分别标记添加员工、设计角色和编辑员工配置。

## 实测

使用实际 `App`、共享导航、真实 WorkforceService、SQLite 和 Store 目录，在独立临时资料目录运行；未修改日常应用员工数据，未调用模型。

| 场景 | 结果 |
| --- | --- |
| 活动栏：搜索“产品” → 查看详情 → Esc | 搜索保留；焦点回到查看按钮；员工页仍为空且没有草稿 |
| 明确添加 → 修改专业方向 → 返回我的员工 | 草稿保存；菜单全部恢复可点击 |
| 切换知识与决策 → 返回员工 → 继续草稿 | 原步骤及专业方向恢复 |
| 走完声明技能/确认 → 仅保存 | 生成员工 v1；模板目录不被修改；无技能安装副作用 |
| 员工档案 → 编辑 → 返回 → 项目空间 | 正常切换；未遗留 busy 禁用状态 |
| 分组栏：继续员工草稿 → 返回 → 角色库 | 正常切换；面包屑与标题正确 |
| 详情打开时断开验证服务 → 添加 | 弹层内显示失败；按钮恢复；关闭后可切换菜单 |
| 中文浅色、英文深色、390px 窄容器 | 详情可读、正文可滚动、底部动作可达 |
| Breadcrumb 样式读取 | nav/ol padding=0，ol margin=0、list-style=none |
| `npm run build` | 通过（含 TypeScript）；保留现有体积与混合导入告警 |

截图目录：[角色详情与导航证据](../../../agent-flow/designs/agent-workforce/review/role-details-fix-2026-10-26/)。窄容器为组件验证，两种侧栏为实际 App 浏览器运行；本轮未重跑原生 Electron、打包安装或外部模型任务。
