# 专家创建与技能推荐：本地实施记录

日期：2026-10-28。范围：源码、本地与隔离环境。依赖顺序是签名 Store 和固定制品 → 宿主召回及验签 → 创建界面和准备流程 → 运营检查、状态发布 → 联调。仓库原有未提交变更予以保留；本记录描述本次与先前工作叠加后的结果，不把全部工作归因于本次。

2026-10-28 用户进一步决定：产品尚未正式发布，不需要旧客户端兼容。本次撤回按精确 release 处理，旧版本撤回不应阻止同技能新版本；已有专家、选择和运行中任务的固定引用仍不可静默替换。其他历史文档中与旧客户端兼容有关的目标以本决定为准。

## 实现与边界

- **创建体验**：`src/WorkforceRoleEditor.tsx` 和 `src/Workforce.tsx` 实现添加入口、构思、定义、技能、确认与草稿往返；建议按字段采用，技能只在用户单项选择后加入。离开未修改页面不新增草稿，恢复草稿后放弃本次更改保留进入时的内容。
- **AI 辅助**：`core/workforce/role-drafts.cjs` 和 `core/workforce/skill-suggestions.cjs` 使用宿主内版本化规则，不引入会全局触发的内部 Skill。仅创建界面显式请求调用模型；匹配只使用本地验签候选，服务端不接收角色自由文本。停止可中断请求；输入、快照和请求身份变化时旧结果不能应用；应用前再次核验身份和发布状态。不自动安装、赋权或修改已选技能。详细内部命令和数据边界见 [API 契约](role-skills-api-v1.md)。
- **Store**：复用既有公开签名目录、双语投影、固定制品、角色绑定、缓存和提交准备流程。新增 `scripts/check-curated-sources.cjs` 手动检查已收录来源，限流/失败保留上次观察并形成待审核项；它不发布、不安排定时执行。新增 `scripts/publish-release-status.cjs` 在隔离目录中生成带审核记录的签名代际，并以单个指针切换。审核通过仍是人工操作，第三阶段的大规模发现、运营界面和监控未实现。
- **发布限制**：状态发布、普通内容代际激活和回环服务器切换已在隔离环境验证；激活器校验签名、固定版本、制品和历史资料后切换。不得直接覆盖当前代际，操作需串行；首次初始化、跨主机协调与断电持久化尚未验证。未对线上 Store 进行本轮发布。

## 后续优化：专家对话式构思

同日根据用户决定，将构思页从一次性建议改为多轮对话：`src/ExpertGuide.tsx` 复用聊天输入和动态表单字段；`core/workforce/role-drafts.cjs` 负责会话草稿、生成、取消、版本检查及使用现有 `normalizeDynamic` 校验选择问题。单次请求最多提出一个选择问题；自由文本可直接继续。AI 建议仅经用户采用后进入角色字段，批量采用只填空白，技能不自动安装。现阶段这不是项目聊天的完整 Agent 运行时，也不支持在专家引导里执行任意工具或多步骤业务模板。

隔离测试覆盖问题协议、连续回答、未采用不改配置、草稿恢复、无效问题、取消和迟到响应，以及生成时输入草稿与角色变更。完整 Node 测试 499 项中 498 通过、1 跳过；浏览器使用模拟模型通过 8 项交互及窄窗口测试。真实 DeepSeek 测试仅使用虚构差旅专家及虚构回答，两轮均返回，第一轮产生有效声明式选择问题，未自动安装技能；不代表所有模型和业务都能稳定生成问题。实际完整桌面打包版、Windows 与辅助功能矩阵仍待验证。日志和截图保存在 `agent-flow/.state/expert-guide-20261028/`。
