# 主持人驱动的任务规划与修订

本轮实现：讨论是规划主入口；手动编辑是同一份草稿的补充入口。任务定义、图、执行状态均使用现有任务服务，避免在聊天里维护一张独立的示意图。

## 操作与边界

- 用户明确要求生成／修改任务，主持人选择 `plan`，准备或更新当前话题的持久化草稿。明确另建目标使用 `new-plan`，不覆盖已有计划。
- 解释／讨论合理性使用 `reply` 或 `ask`，不改任务数据。节点解释按钮限定只读 `reply`。选择节点后，输入区展示可移除的节点引用，服务端验证它属于本话题的当前计划。
- 规划初稿之后检查节点、成员授权、验收条件和项目关系。复用已确认关系；新关系用现有声明式表单确认，写入空间约定。未知连接状况留给有边界的执行核验，不能凭关系推断 SSH 当前在线。
- 计划说明和现有 React Flow 组件直接读取草稿／计划数据。当前流程默认收起，通过输入框上方的“查看计划”进入；历史回复保留草稿版本与修改摘要，不提供旧版本启动按钮。
- 用户在原聊天输入框追问、修改或提交补充信息。打开页面／流程／手动编辑不会自动调用模型。手动保存后，主持人读取最新草稿。
- 新计划“确认并保存”不执行；“确认并启动”依次保存、启动，启动失败保留已保存计划，避免重复创建。
- 已保存计划的修改进入独立修订草稿，记录基础计划 ID／版本。讨论期间不停止原计划；应用修订时明确确认暂停整个计划，等待停止后保存。变更节点和受影响下游重新执行或验收，旧历史保留，修订不自动重启。
- 基础版本变化时禁止应用旧修订。后续明确修订以最新正式计划为基础；原草稿保留可查看。草稿与计划均有版本校验，迟到模型回复不覆盖手动编辑。
- 停止主持人会同时取消任务规划请求；已保存草稿与用户输入保留。讨论中的规划请求没有固定总时限，持续收到有效文本就继续，连续 5 分钟无新文本才结束等待，仍可随时停止。独立的手动引导保持原有超时策略。

## 实际状态与汇报

`status` 使用查询时的计划／节点状态、实际 run 状态、验收记录、阻塞原因、授权请求和持久化补充请求。未提交表单答案不发送给主持人。回复标明查询时间，执行完成不等于验收通过；缺失读取结果明确为未知。

本轮是用户发问或点击“汇报进展”后的汇报。后台主动推送阶段进展、自动接受结果、自动批准授权不在本轮实现范围。

## 代码路径

- `core/workforce/discussion-plans.cjs`：话题内目标解析、当前计划与进度读取、调用任务引导服务。
- `core/workforce/discussion-host.cjs`：结构化主持人动作、规划状态、取消传播和结果记录。
- `core/workforce/task-guide.cjs` / `plans.cjs`：来源更新、修订草稿、关系检查与显式应用。
- `src/DiscussionPlan.tsx`：同一话题内的当前流程、节点详情、声明式补充、确认保存／启动／应用。
- `src/TaskCreationGuide.tsx`：直接打开既有草稿作为手动兜底。

## 引导退出与重新梳理（聊天优先）

审查结论：这是 Operate 产品交互，保留宿主字体、语义色与 shadcn 组件。设计参数为 DESIGN_VARIANCE 3、MOTION_INTENSITY 1、VISUAL_DENSITY 5；不引入新的视觉系统或装饰动效。长引导尾随所有消息、顶部退出按钮离开视口，以及手动引导替换聊天输入框，是“模型没反应”的共同原因。

- 默认只展示输入框上方的计划名称、状态及“查看计划”入口。进入/返回话题不会自动展开长图和表单。
- 查看计划或手动编辑时，输入框旁的同一位置变为“返回对话”，不会随表单内容滚走。不增设弹层或自动改变侧栏宽度。
- 每次发送主持人消息都收起旧引导，显示正在发送、主持人状态和回复。聊天输入框始终发送给主持人；手动编辑仅通过表单按钮提交。离开手动编辑取消未完成的整理请求，迟到响应不得抢回页面。
- 表单未提交内容继续保留在本机。收起是展示状态，不会暂停或取消正式计划执行。
- 按钮“重新引导”发送明确的 restart-guide 意图；聊天中“开始新的引导”等自然表达由主持人选择同名结构化动作，不做关键词替换路由。只读解释接口不能返回重启动作。
- restart-guide 在同一话题创建空白草稿，保留旧稿及正式计划，不自动调用规划模型或启动执行。主持人用一句话说明重启，并询问一个新目标问题，不弹出旧确认表单。
- 新稿记录 sourceFromRequestId；后续主持人上下文及草稿来源刷新从这条用户消息开始，避免重新带入旧的未确认要求。共享且已确认的项目职责/关系仍可复用。旧稿可以在选择器中主动回查。
- 此次 DeepSeek 实测为隔离数据库与虚构项目：生成计划 → 自然语言开始新的引导 → 重新询问目标。无专家执行，无部署，无用户数据修改。证据：`evidence/discussion-guide-restart-2026-11-04.json`。
